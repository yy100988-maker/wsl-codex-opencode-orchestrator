# 配置参考

配置文件：`.opencode/wsl-config.json`

文档导航：[快速开始](快速开始.md) / `[[快速开始.md]]`， [任务协议](任务协议.md) / `[[任务协议.md]]`， [运行机制](运行机制.md) / `[[运行机制.md]]`。

## 完整示例

```json
{
  "schema_version": 1,
  "wsl": {
    "distro_name": "Ubuntu",
    "project_root": "/home/<user>/projects/<project>",
    "windows_project_root": "D:\\CODEX\\<project>"
  },
  "models": {
    "implementation": "opencode-go/deepseek-v4-flash",
    "fallback": "opencode-go/gpt-5.6-luna",
    "validation": "opencode-go/deepseek-v4-flash"
  },
  "scheduler": {
    "max_concurrent_agents": 100,
    "max_new_agents_per_cycle": 20,
    "monitor_interval_seconds": 30,
    "max_task_runtime_seconds": 7200,
    "stall_timeout_seconds": 600,
    "task_start_delay_ms": 500
  },
  "memory": {
    "wsl_resume_below_percent": 80,
    "wsl_stop_admission_percent": 88,
    "wsl_critical_percent": 90,
    "windows_resume_below_percent": 80,
    "windows_stop_admission_percent": 88,
    "windows_critical_percent": 90,
    "windows_reserve_mb": 4096
  },
  "cleanup": {
    "term_grace_seconds": 15,
    "kill_grace_seconds": 5,
    "delete_validated_worktrees": true,
    "archive_failed_worktrees": true
  }
}
```

## 字段说明

| 路径 | 说明 | 建议 |
|---|---|---|
| `wsl.distro_name` | 明确的 WSL2 发行版名 | 不依赖默认发行版 |
| `wsl.project_root` | WSL Linux 项目根目录 | 优先 `/home/...`，避免高并发使用 `/mnt/d` |
| `models.implementation` | 默认实现模型 | `opencode-go/deepseek-v4-flash` |
| `models.fallback` | 主模型不可用时的唯一回退 | `opencode-go/gpt-5.6-luna` |
| `scheduler.max_concurrent_agents` | 最大同时运行任务数 | 不超过 100，并受内存限制 |
| `scheduler.monitor_interval_seconds` | 调度检查周期 | 默认 30 秒 |
| `scheduler.max_task_runtime_seconds` | 单任务最大运行时间 | 默认 7200 秒 |
| `scheduler.stall_timeout_seconds` | 日志无进展超时 | 默认 600 秒 |
| `memory.*` | WSL/Windows 双层内存阈值 | 停止阈值高于恢复阈值 |
| `cleanup.term_grace_seconds` | SIGTERM 等待时间 | 默认 15 秒 |

## 阈值规则

- 任一侧内存达到 `stop_admission_percent`：停止新增任务。
- 任一侧达到 `critical_percent`：优先清理已结束任务和处理 Gate。
- 两侧都低于恢复阈值：恢复任务准入。
- Windows 主机必须保留 `windows_reserve_mb` 可用内存。

## 安全建议

- 不把 API key、token 或 cookie 写入配置文件。
- 不把 `.opencode/` 运行日志直接提交到公开仓库。
- 不把 `project_root` 指向不受控的共享目录。
- 默认要求 Git 工作区干净；脏工作区必须先建立 baseline，或显式设置 `wsl.allow_dirty_project=true`。
- 修改模型前先用 `opencode models` 和一次最小请求验证可用性。
