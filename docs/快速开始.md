本文用于第一次在 Ubuntu WSL2 中运行本项目。

## 前置条件

1. Windows 已启用 WSL2。
2. 已知发行版名称，例如 `Ubuntu`。
3. 项目已位于 WSL Linux 文件系统。
4. WSL 账户具备安装依赖的权限和网络访问；Supervisor 会自动安装 Linux 版 OpenCode 到 `~/.opencode/bin`。认证仍需在 WSL 内执行 `opencode auth`。
5. 当前用户可以通过 sudo，或者允许 WSL 启动同一发行版的 root 命令。

## 准备项目

```bash
cd /home/<user>/projects/<project>
mkdir -p .opencode
git status
opencode auth
```

主控 agent 应先根据需求文档和详细设计文档生成：

- `.opencode/wsl-config.json`
- `.opencode/tasks.json`
- `.opencode/prompts/<task-id>.md`

## 启动

```powershell
wsl.exe -d Ubuntu -- bash -lc 'cd /home/<user>/projects/<project> && bash /path/to/scripts/supervisor-loop.sh .opencode/wsl-config.json'
```

启动顺序如下：

1. 单实例锁，防止同一项目启动两个 Supervisor。
2. 自动检查并安装固定白名单系统依赖。
3. 校验 Git、路径、OpenCode 和模型。
4. 检查 WSL 与 Windows 主机内存。
5. 按任务依赖和文件 Lease 启动 OpenCode。
6. 任务结束后运行 Gate。
7. Gate 通过才合并，否则归档 worktree。
8. 释放 Lease 并记录事件。

## 停止

在 Supervisor 终端按 `Ctrl+C`。正在运行的任务不会被宽泛杀进程；需要清理单个任务时，使用其 task id：

```bash
bash scripts/process-manager.sh stop .opencode/orchestrator-state.json <task-id>
```

## 验证安装

```bash
bash tests/orchestrator-smoke.sh
```

smoke 测试只验证 worktree、handoff、Gate 和清理链路，不调用真实模型。
