# 故障排查

文档导航：[快速开始](快速开始.md) / `[[快速开始.md]]`， [配置参考](配置参考.md) / `[[配置参考.md]]`， [返回 README](../README.md) / `[[README.md]]`。

## 预检失败

```bash
bash scripts/ensure-dependencies.sh
bash scripts/preflight.sh .opencode/wsl-config.json
```

优先查看 JSON 中的 `errors`。常见原因：

| 错误 | 处理 |
|---|---|
| `sudo-password-required` | 首次手动安装，或允许 WSL root 回退 |
| `linux-filesystem-required` | 将项目移动到 `/home/<user>/projects` |
| `not-git-repository` | 初始化或修正 `project_root` |
| `model-not-listed:*` | 检查 OpenCode provider、模型名和认证 |
| `missing:opencode` | 在 WSL 内安装 Linux 版 OpenCode，不使用 Windows 版 |

## 任务没有启动

检查：

```bash
jq . .opencode/tasks.json
jq . .opencode/orchestrator-state.json
cat .opencode/leases.json
free -h
```

可能原因：

- 依赖任务还没有完成。
- `allowed_files` 与运行中的 Lease 冲突。
- WSL 或 Windows 主机内存达到停止准入阈值。
- 达到 `max_concurrent_agents`。
- 任务已经在 history 中完成或阻塞。

## 进程没有退出

查看任务记录：

```bash
bash scripts/process-manager.sh status .opencode/orchestrator-state.json <task-id>
ps -o pid,pgid,lstart,cmd -p <pid>
```

只清理对应任务：

```bash
bash scripts/process-manager.sh stop .opencode/orchestrator-state.json <task-id>
```

不要直接结束所有 `node`、`bun` 或 `esbuild` 进程。

## Gate 失败

```bash
jq . .opencode/gates/<task-id>/result.json
cat .opencode/logs/<task-id>.log
cat .opencode/worktrees/<task-id>/.opencode-handoff.json
```

重点检查：

- 是否写入 handoff。
- changed files 是否都在 `allowed_files` 内。
- 任务测试命令是否能在该 worktree 独立运行。
- 是否存在跨模块修改或未声明风险。

## 生成清理报告

```bash
bash scripts/report-builder.sh /home/<user>/projects/<project>
```

报告默认输出到 `.opencode/reports/资源清理报告.md`。
