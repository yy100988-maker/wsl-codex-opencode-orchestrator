# 任务协议

任务文件：`.opencode/tasks.json`

文档导航：[配置参考](配置参考.md) / `[[配置参考.md]]`， [运行机制](运行机制.md) / `[[运行机制.md]]`， [返回 README](../README.md) / `[[README.md]]`。

## 任务示例

```json
{
  "tasks": [
    {
      "id": "api-user-service",
      "title": "实现用户服务接口",
      "prompt": "根据分配的模块设计实现用户服务接口，并完成任务级测试。",
      "allowed_files": [
        "src/user-service/**",
        "tests/user-service/**"
      ],
      "base_commit": "<task-creation-commit>",
      "depends_on": [],
      "required_gates": ["scope", "handoff", "static", "unit"],
      "test_command": "npm test -- tests/user-service",
      "lease_ttl_seconds": 3600,
      "status": "pending"
    }
  ]
}
```

## 必填字段

| 字段 | 类型 | 规则 |
|---|---|---|
| `id` | ASCII 字符串 | 全局唯一，建议使用模块名加动作 |
| `allowed_files` | 字符串数组 | 必须是相对项目根目录的文件或目录模式 |
| `prompt` | 字符串 | 只包含该任务模块的设计约束和验收目标 |
| `base_commit` | Git 提交号 | 任务创建时固定，Gate 和归档不得改用运行时主分支 HEAD |

## 可选字段

- `title`：用于报告和日志显示。
- `depends_on`：前置任务 id 数组。
- `test_command`：任务完成后的只读验收命令。
- `required_gates`：必需 Gate；要求 Contract、Integration 或 Security 时必须同时提供对应 `gate_commands`。
- `gate_commands`：额外 Gate 命令映射。
- `lease_ttl_seconds`：文件租约有效期。
- `status`：初始状态通常为 `pending`。

## 拆分规则

1. 先展开 `allowed_files` 到当前 Git 工作区的实际源码文件，再生成任务；目录通配符不能作为最终并行边界。
2. 每个实现任务默认只拥有一个源码文件；同一源码文件不得同时出现在两个 active 任务中。
3. 共享类型、数据库迁移、路由注册等高冲突文件应单独设为串行任务。
4. 如果两个原始任务命中同一源码文件，后一个文件任务自动依赖前一个文件任务。
5. 每个 prompt 只传递该任务所在文件的设计信息，公共约束写入项目级记忆。
6. 测试 agent 不进入实现任务的 `allowed_files`，不产生业务代码提交。

## Handoff 要求

实现 agent 必须在 worktree 根目录写入 `.opencode-handoff.json`，至少说明：

```json
{
  "completed": true,
  "summary": "完成的实现摘要",
  "changed_files": ["src/user-service/service.ts"],
  "tests": ["npm test -- --runInBand tests/user-service"],
  "known_risks": []
}
```

`completed: true` 只代表 agent 自报完成，不代表任务已经验收。最终状态必须以 Gate 结果为准。

## 固定基线和完成条件

任务创建时必须写入 `base_commit`。Gate 使用 `base_commit` 到任务分支提交的固定范围计算 changed files，不能使用执行 Gate 时的主分支 HEAD。任务分支没有真实提交、没有业务文件变更或合并后无法验证 changed files 已进入目标分支时，必须标记 `blocked`。

`not-configured` 不是通过状态。任务要求的 Contract、Integration 或 Security Gate 没有配置命令时，必须阻止任务合并；不需要的 Gate 必须明确不写入 `required_gates`。
